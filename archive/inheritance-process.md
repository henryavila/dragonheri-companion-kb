# Processo de Herança de Conta Veterana (Legacy Character Inheritance)

## Passo a Passo Completo

### 1. Login com Mesma Conta
- Use a MESMA conta third-party (Google, Facebook, Apple) do jogo original
- Se não lembra qual usou, tente todas até encontrar

### 2. Seleção de Servidor
- Na tela de servidor, clique em **"Veteran Server"**
- ⚠️ NÃO clique em "Existing Character" — isso reconecta ao server antigo com level resetado
- Veteran Server cria novo personagem que PODE herdar a conta antiga

### 3. Criar Personagem
- Escolha raça, nome, aparência normalmente
- Após criação, entre no jogo e complete o tutorial inicial

### 4. Herança (PASSO CRÍTICO)
- Vá em: **Menu → Event → Legacy Character Inheritance** (bottom da lista de eventos)
- ⚠️ Também pode aparecer como ícone de orc no canto superior direito
- Selecione seu personagem legado na lista
- Verifique o resumo: heróis, scrolls, Wyrmarrow, artefatos
- Clique em **"Confirm"**

### 5. Confirmação
- Heróis S1 aparecem imediatamente no roster
- Wyrmarrow creditado na conta
- Artefatos disponíveis para equipar
- Skill Scrolls devolvidos avulsos (level 1)

## Bugs Conhecidos e Soluções
- **Skill Scroll count incorreto:** Bug identificado e corrigido pelos devs. Se persistir, contate service@sgrastudio.com com Role ID
- **Heróis "desaparecidos":** Originalmente S2-S4 ficavam trancados, mas em Fev/2026 todas seasons já passaram — devem estar disponíveis
- **Nada apareceu após herança:** Verifique se completou TODOS os passos em Event > Legacy Character Inheritance
- **EU vs US:** Alguns jogadores US relataram perda — usar ticket de suporte

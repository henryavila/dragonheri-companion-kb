# Sistema de Combate

## Mecânica Base
- RPG em tempo real com formação de heróis
- Heróis atacam automaticamente (auto-battle)
- Ultimates podem ser manuais (recomendado) ou auto
- Posicionamento importa: frente (tanks) e trás (DPS/support)

## Formação
- 5 heróis deployados por time
- Posição frontal: Tanks/Defensores (absorvem dano)
- Posição traseira: DPS e Supports
- Spread out: evitar AoE inimigo concentrado

## Tipos de Skill
1. **Passive:** Trigger automático em condições específicas
2. **Battle Skills:** Usadas automaticamente, com recharge timer (primeiro uso é mais rápido)
3. **Ultimate:** Recarrega visivelmente, uso manual recomendado. Habilidade mais poderosa.

## Atributos dos Heróis
| Atributo | Efeito |
|---|---|
| HP | Vida total |
| ATK | Dano base (maioria dos skills escala com ATK) |
| DEF | Redução de dano recebido |
| Crit Rate | Chance de acerto crítico |
| Crit Damage | Multiplicador do crítico |
| Accuracy | Chance de acertar (relevante para PvP) |
| Attack Speed | Velocidade de ataque (relevante para Dauntless) |
| Skill Haste | Reduz cooldown de skills |

## Dicas de Combate
- Espalhe heróis para evitar AoE
- Tanks na frente, DPS/Support atrás
- Use ultimates manualmente em momentos estratégicos
- Analise info do inimigo ANTES da batalha
- Se falhar e sair, recursos são reembolsados
- Troque heróis conforme o conteúdo — elemental resistance varia

## Personagem Principal (Adventurer) em Combate

O Adventurer (PC) **ocupa 1 dos 5 slots** do time — é opcional, pode entrar ou ficar de fora.

- **Ocupa slot:** Se incluído, o time fica PC + 4 heróis. Se excluído, 5 heróis normais.
- **Control Skill:** Inimigos mortos geram Energy Dust → quando acumula, o PC solta AoE de dano em todos inimigos + Shield em todos aliados. Funciona mesmo com o PC fora do time (exceto Grand Gladiator Arena).
- **Elemento relevante:** PC tem acesso a Fire, Ice e Lightning; troca via Psychicore > Element Power (grátis, a qualquer momento). O elemento escolhido conta para Elemental Bonds/sinergias do time.
- **Classe (Soldier/Thief/Archeologist/Actor):** Irrelevante para combate — afeta apenas exploração no overworld (Thief = lockpicking, etc.)
- **Limitação:** Só acessa Fire, Ice e Lightning — não tem Poison, Necrosis ou Radiance.
- **Tier lists:** Nenhuma tier list inclui o PC nos rankings de heróis.

> **Para Henry:** SuperYennefer (Fire, Support school) complementa o bond S4 Fire+Poison e contribui para Support bond (cross-element). Vale incluir no time se precisar de mais um Fire para ativar bond, caso contrário usar 5 heróis especializados é geralmente superior.

## Auto-Battle
- Disponível para replay de conteúdo já completado
- 2x speed disponível (gratuito no Reborn)
- Auto-spellcasting liga uso automático de ultimates
- Importante: auto-repeat fecha se sair do jogo no celular

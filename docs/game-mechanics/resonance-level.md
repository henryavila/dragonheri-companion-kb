# Sistema de Resonance Level

## Conceito
O Resonance Level substitui o antigo sistema de level individual de heróis. Agora, toda XP ganha vai para um pool compartilhado da conta. Quando o Resonance Level sobe, TODOS os heróis da conta sobem junto.

## Como Funciona
- XP de qualquer fonte → pool único → Resonance Level da conta
- Herói novo adquirido → imediatamente no Resonance Level atual
- Sem necessidade de farmar XP individual para cada herói
- Foco muda para composição e sinergia, não grind de level

## Breakthrough System
- A cada 10 níveis: Breakthrough Trial (teste de conta)
- Completar dá bônus account-wide:
  - Redução de velocidade de ultimate dos inimigos
  - Aumento de dano dos aliados
  - Benefícios gerais para todo o roster

## Marcos Importantes
| Resonance Level | Desbloqueio |
|---|---|
| 20 | Recompensas de pré-registro disponíveis |
| 30 | Hero Captain Skill / Enhanced Skill (2★) |
| 50 | Artifact slot desbloqueado (3★) |
| 70 | Positive Rune slot (4★) |
| 79 | Adventure Team rewards (3.000 Wyrmarrow) |
| 90 | Negative Rune slot (5★) |
| 99 | Todas as recompensas do Account Appraisal desbloqueadas |
| 100 | Level máximo (Rank 5) |

## Farm Eficiente de Resonance Level
1. **Goblin Dungeon** → melhor ratio XP/stamina
2. **Adventure Mode** → sempre avance até o cap primeiro
3. **Daily stamina refills** → 150 gems cada (primeiros 2 refills)
4. **4x reward multiplier** → use quando disponível em dungeons

## Eliminação de Bottlenecks Antigos
- Antigo: Level caps em 30, 50, 70, 90 exigiam materiais elementais específicos
- Novo: Breakthrough Trials substituem → sem material farming per-element
- Resultado: Experimentar heróis diferentes é muito mais acessível

## Impacto para Veterano (Henry)
Com 118 heróis herdados, todos começam no mesmo Resonance Level. Não há desvantagem em ter muitos heróis — na verdade, ter opções é vantagem pura para montar times diferentes conforme o conteúdo exige.

# Sistema de Gear e Equipamento

## Slots de Equipamento
- 4 básicos: Arma, Armadura (Breastplate), Elmo, Manopla
- Desbloqueáveis com star rank:
  - 3★ (Lv.50): Artifact slot
  - 4★ (Lv.70): Positive Rune slot
  - 5★ (Lv.90): Negative Rune slot
- Total: 7 slots por herói

## Raridades de Gear
Common → Rare → Epic → Mythic
- Mythic: melhor gear, obtida em dungeons avançadas
- Gear sets Mythic: bônus de 2 e 3 peças

## Gear Sets S4 (Novos)
| Set | Bônus 2pc | Bônus 3pc | Ideal para |
|---|---|---|---|
| Echoes of War | +ATK, +Atk Speed | +Atk Speed, +basic atk dmg on crit | Dauntless / basic attackers |
| Whispers of the Order | +ATK, +Skill Haste | +Ultimate skill damage | Casters / skill users |
| Oasis Aspiration | +HP, +Skill Haste | -Damage taken when HP high | Tanks |

## Prioridade de Stats por Função
| Função | Stats | Gear Priority |
|---|---|---|
| DPS/Carry | ATK, Crit Rate, Crit Damage | Arma + sets ofensivos |
| Tank | HP, DEF | Armadura + sets defensivos |
| Support | Accuracy, HP, Skill Haste | Mix |

## Regras Importantes
- **Troca de gear é GRATUITA** — experimente sem medo
- **Não faça upgrade pesado em gear comum** — espere Mythic
- **4 peças de gear podem ser guardadas entre seasons** — escolha bem
- **Gear só pode ser carregada 1 vez** (forward once)
- **Batch sell** gear desnecessário para gold

# Modos de Jogo

## PvE

### Adventure Mode (História Principal)
- **Prioridade #1** — desbloqueia todos os outros modos
- Exploração open-world dividida em shards/regiões
- Side quests, puzzles, NPCs interativos, baús escondidos
- Skill checks baseados em atributos do personagem (STR, DEX, CHA, etc.)
- Regiões: Shadowy Forest, Scorching Sand Sea, Mysterious Underground, Vast Archipelagos
- S4: Sea of the Dead (novo mapa sandbox)

### Dungeons
| Dungeon | Reward | Prioridade |
|---|---|---|
| **Goblin Lair** | EXP Potions | Alta — melhor XP/stamina |
| **Elemental Dungeons** | Materiais de evolução | Alta |
| **Catacombs** | Gear drops | Média |
| **Ruins** | Gear alternativa | Média |

- Auto-battle disponível para replay
- Dificuldade escala — monstros ganham resistência elemental em níveis altos
- Trocar heróis conforme resistência do dungeon

### Fey Meander
- **300 andares** (expandido no Reborn)
- **Full auto-challenge mode** — seus times escalam automaticamente até perder
- Excelente progressão passiva — deixar rodando em background
- Rewards escalam com andares completados

### Ancestral Ruins (Novo no Reborn)
- Modo **roguelike**
- Escolha de caminho (path selection)
- Após cada batalha: pick a card → buff de stats/composição
- Heróis rotativos grátis semanalmente — sem gear/talent advantage
- Bom para testar heróis que não tem

### Infinite Challenge (Novo no Reborn)
- Roguelike puro de skill
- Testa conhecimento de mecânicas e composição

### Expedition Mode (Novo)
- Foco em otimização de guild/time
- Build de guild → fight tougher enemies
- Todos heróis podem brilhar

## PvP

### Temporal Vortex
- Ranking PvP principal
- Fire/Burn domina no meta atual
- **Não priorizar no início** — foque PvE primeiro
- Volte com times melhores para melhorar score

### Arena (Guild War)
- Competição entre guildas
- Requer roster diverso

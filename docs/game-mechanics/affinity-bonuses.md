# Bônus de Afinidade (Estado Atual)

> **Nota:** Valores escalam com progressão da conta. Henry atualiza quando mudar.
> **Afinidade = grupo elemental** (ex: Permafrost = Ice + Necrosis, Ulceration = Poison + Fire, Resplendence = Lightning + Radiance)

- +20 DEF
- +200 HP

## Impacto atual
Bônus é **flat (fixo)**, não percentual. Em early game o impacto é pequeno.
Conforme a conta progride, os bônus mudam para % e se tornam mais relevantes.

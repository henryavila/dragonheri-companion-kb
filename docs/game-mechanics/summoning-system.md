## Tipos de Banner

### Selected Summons (rotativos)
- **Pool:** ~14-16 Legendarios, sendo **2 "Premium"** (featured/rate-up)
- **Rotacao:** muda periodicamente (numerados: Selected Summons I, II, III...)
- **Pity:** 70 pulls = 1 Legendary (provavelmente com peso maior para Premium)
- **Premium heroes** = destacados no banner, aparecem com selo "Premium" no pool
- **NAO garante heroi especifico** — mas Premium tem chance maior

### Prophecy Summons
- **Ativado via Prophecy Code** (codigo pre-gerado)
- **Pool:** muitos herois marcados "Premium" (~10+)
- **Mesmas rates:** 1.5% Legendary, 70 pity
- **Prazo:** 30 dias para usar o codigo

### Banner Exclusivo (300 pulls)
- **300 pulls** = heroi especifico do banner garantido
- **Custo:** ~30.000 Wyrmarrow
- **Unica forma de GARANTIR um heroi especifico**
- Inacessivel para F2P no curto prazo
